# Data Directory

This directory contains output files generated by the scraper.

## Output Files (Generated Automatically)

- **uoc.jsonl** - Raw scraped data (one JSON per line)
- **UnitsData.xlsx** - Maritime format Excel workbook (7 sheets)
- **error-log.json** - Logs errors, duplicates, and invalid codes

**Note:** These files are in .gitignore. Each user generates their own based on Units.xlsx input.
